# 初版验证记录

2026-09-28，版本 0.1.0。

- Node 内置测试：9 项通过，覆盖配置恢复、日记边界、组合限制、全部 137 个素材存在、状态优先级和原工具接口。
- JavaScript 语法检查与 Git 空白检查通过。
- 本地 Chromium 133 + Playwright：1280×900 桌面、390×844 手机视口均通过。
- 浏览器检查：入口与面板尺寸、缺失工具提示、工具延迟加载、工作台／画室／Meow 打开、两个画图工具的忙碌状态、dry-run 忽略、聊天生成与停止、拖动及刷新持久化、喂食日记与书摘交接、贴贴、隐藏恢复、缩到 320×400 后位置约束、重复初始化、专注结束、清理。

- 仅测试了模拟的 SillyTavern 上下文和依据原项目实现的接口夹具。未登录用户的真实酒馆，未调用真实 API 或测试付费生图。

安装后仍请在实际酒馆主题、手机浏览器及现有脚本组合下体验；遇到问题可提供截图和触发步骤。
