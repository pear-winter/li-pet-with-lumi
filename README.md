# 梨间雪 · 酒馆桌宠

梨梨 × Lumi 的 SillyTavern 桌宠初版。把桌面版的六只像素伙伴带到酒馆里，从 **魔法棒 → 梨间雪 · 酒馆桌宠** 打开。

## 安装

在 SillyTavern 的「扩展 → 安装扩展」里粘贴：

```text
https://github.com/pear-winter/li-pet-with-lumi
```

安装后刷新酒馆，打开聊天输入框旁的魔法棒，选择「梨间雪 · 酒馆桌宠」。扩展设置里也有入口。目标版本为 **SillyTavern 1.19.0 或更新版本**。

这是酒馆原生 UI 扩展，桌宠本体不依赖酒馆助手、不需要 API Key、不调用模型，也不需要运行 Lumi 的 Windows 桌面程序。手机和电脑的酒馆页面都可以使用。

## 初版可以做什么

- 六只可选伙伴：千千猫猫、梨梨兔兔、哥哥狗狗、梨梨哥哥、煤球猫猫、灰鸮g老师；默认放出兔兔和猫猫。
- 点一下摸摸，拖动移动，右键打开面板；手机从魔法棒操作即可。
- 喂食、叫醒、睡觉、散步；一分钟没有互动会睡觉。
- 双人贴贴与叠叠乐；拖到另一只附近可以触发叠叠乐。遵守原版三组不贴贴组合，g老师只参与双人看书贴贴。
- 聊天输入、生成回复时陪伴开工；结束、停止、切换聊天后恢复。
- 25 分钟专注，时间到后提醒休息。页面关闭时不发送系统提醒；下次打开会结算已到期的这一段。
- 自定义称呼、大小、散步速度、气泡；隐藏、恢复、找回跑到边缘的伙伴。
- 位置与偏好保存在当前酒馆用户的扩展设置中。适配手机屏幕旋转和软键盘可视区域。
- 简单陪伴日记：只记录摸摸、喂食、贴贴／叠叠乐和完成专注的次数，保留最近 30 天；可复制或送入工作台书摘编辑窗口。

## 和其他工具一起用

在「一起做事」页检查工具状态。扩展不会自动下载、重装或改写这些工具。

| 工具 | 已核对版本 | 初版联动 |
| --- | --- | --- |
| 梨梨工作台 | 3.6.1，用户提供脚本 | 从已有顶部或悬浮入口打开；工作台打开时安静专注；日记送到书摘编辑窗口，由用户确认保存 |
| 梨梨画室 | 3.9.1，用户提供脚本 | 使用已有 `open()` 接口打开；观察忙碌指示，跟随任务状态 |
| [Lumi 的 Meow · 猫猫星绘](https://github.com/Lumi729/meow) | 0.9.15 | 从原入口打开；观察 `aria-busy` 跟随任务状态 |

原有工具需要先安装、启用并成功初始化。工作台的顶部／悬浮入口不能同时关闭，否则当前版本无法打开；缺少书摘的工作台版本不能接收日记。画室的忙碌指示包含生图和其他等待任务，桌宠不会把“任务结束”误报为“生图成功”。Meow 的任务也包括副 API 操作。

这里只打开工具和读取界面忙碌状态，**不会自动发起收费生图、读取 Key 或聊天正文、替换原有设置**。脚本晚于桌宠启动也能检测，无需固定加载顺序。

## 初版边界

酒馆版仅在酒馆页面内显示，不会悬浮到其他应用之上。桌面版的天气、系统窗口感知、跨设备串门、联网配对、Claude/Codex hooks、多宠复杂剧情和录制 GIF 尚未移植；也没有同步桌面版设置或日记。

角色和动画来自 [Lumi729/desk-pets v1.0.24](https://github.com/Lumi729/desk-pets/releases/tag/v1.0.24)，随扩展提供 137 个本地 GIF，打开时不用再访问 GitHub。详见 [素材与协作说明](CREDITS.md)。

## 更新与排查

在酒馆扩展管理中更新本扩展，再刷新页面即可。看不到入口时，确认扩展已启用且酒馆版本符合要求。伙伴找不到时，进入「小设置 → 把伙伴叫回屏幕边上」。工具显示未检测到时，先单独确认那个工具能正常打开，再点「重新检测工具」。

## 开发与验证

```sh
npm test
npm run check
# 另需安装 playwright 并准备 Chromium，仅用于开发检查
node tests/ui.integration.mjs
```

测试包含本地素材完整性、组合规则、状态优先级、数据归一化、联动接口，以及桌面／手机 Chromium 下的模拟酒馆端到端测试。测试使用模拟事件和工具入口，不代替用户酒馆实机验证；未使用真实上游 Key 发起生图。

架构及后续接力说明见 [docs/INTEGRATION.md](docs/INTEGRATION.md)。
