## 0.3.8 · 每个动作独立大小

- 换装动作 → 选择伙伴和替换动作 → 当前动作大小：48–360px，可单独调节所有单宠动作、自动小动作和互动组合，实时保存；可恢复跟随伙伴大小。
- 切换动作时自动采用对应大小，缩放尽量保持脚底位置，并继续适配拖动边界和输入框上方的重力落点。组合大小为基准尺寸，保留原组合宽高比例并受屏幕边界限制。
- 动作大小随整套皮肤本地保存、导出和导入；旧套装没有动作大小时使用默认继承。

## 0.3.7 · 独立大小与小动作换装

- 小设置 → 分别调整每只伙伴大小：每只可调 48–240px，刷新保留；未单独设置时跟随默认大小，也可全部恢复默认。拖动边界、保存位置、重力落点和互动组合同步适配。
- 换装动作增加「下落、点击与自动小动作」分组，明确列出空中掉落、落地、待机、拖动松手/互动结束及自动观察等素材，继续支持图片链接、本地上传、预览与恢复。
- 增加「通用皮肤」。未单独换图的单宠动作按通用皮肤 → 已换好的主页展示图 → 待机换图回退，避免自动动作切回内置小猫；这些动作使用回退图片的动画，想要不同表现可继续单独换图。未使用任何自定义图时仍用内置动作。
- 通用皮肤可随整套导入导出；组合互动仍使用组合自己的换图。启动时先读取本地皮肤再显示桌宠，减少旧素材闪现。

## 0.3.6 · 整套换装、互动与主页展示

- 换装页的「整套皮肤」支持命名保存到当前浏览器、应用/删除已存套装、导出和导入 JSON。文件内包含替换图片（保留 GIF 动画）及主页展示动作，不依赖原图片链接；未替换的动作使用内置素材。
- 应用或导入替换当前整套换装，名字、主页排序和酒馆行为映射保留。文件最大 128MB，单图仍为 8MB；跨域链接禁止下载时会提示本地上传后重试，不会导出缺图的套装。

- 主页使用每只伙伴选定展示动作的新皮肤；换装页可设置「主页展示动作」，保存后立即更新，刷新保留。
- 默认梨梨兔兔排第一；主页卡片下方可前移、后移调整顺序，保存后刷新保留，不改变桌面伙伴或互动素材顺序。
- 换装动作页跟随当前选中的桌宠；替换动作分为单独动作和与其他伙伴互动。
- 互动显示其他伙伴的自定义名字，并区分贴贴、叠叠乐、一起看书及多人组合。只列出含当前伙伴的现有互动素材，换装不要求伙伴已在桌面。
- 支持互动图预览、链接、本地上传和恢复默认；与原「组合」入口共用同一份图片设置，已有换装保持有效。

## 0.3.5 · 和梨梨工作台联动

## 0.3.3 · 独立动作入口与持续时间

- 点击桌宠，动作和魔法门是独立入口；动作位于魔法门左边。魔法门继续直达各工具。
- 控制面板 → 小设置 → 主动动作持续时间：可选「只做一次」「按时间持续」「直到我取消」。默认按时间持续 120 秒（两分钟），秒数可调整。
- 单宠动作、喂食摸摸、手动双宠互动使用这个设置。GIF 至少完整播放一轮；「只做一次」按图片各帧的实际时长播放一轮后恢复自动行为。静态图片或无法读取的跨域动画请使用按时间持续，或上传本地 GIF。
- 动作面板选完不会自动关闭，可以继续选动作、切换互动或恢复自动动作；可点「关闭动作面板」收起。小设置中也能取消所有主动动作。
- 「直到我取消」期间不会被生成回复、音乐、自动互动打断；主动选择别的动作、恢复自动动作、点击组合散开或移除伙伴可结束。刷新页面后恢复自动行为，时长偏好保留。
- 重力落点在聊天输入区域上方，预留 8px；输入框变高、手机键盘弹出或屏幕旋转时重新适配。没有可见输入框时才使用可见屏幕底部。
- 魔法棒使用原生菜单行，增加图标与文字间距、上下留白；长文字可以换行。

# 梨间雪 · 酒馆桌宠

梨梨 × Lumi 的 SillyTavern 桌宠初版。把桌面版的六只像素伙伴带到酒馆里，从 **魔法棒 → 梨间雪 · 酒馆桌宠** 打开。

## 安装

在 SillyTavern 的「扩展 → 安装扩展」里粘贴：

```text
https://github.com/pear-winter/li-pet-with-lumi
```

安装后刷新酒馆，打开聊天输入框旁的魔法棒，选择「梨间雪 · 酒馆桌宠」。扩展设置里也有入口。目标版本为 **SillyTavern 1.19.0 或更新版本**。

这是酒馆原生 UI 扩展，桌宠本体不依赖酒馆助手、不需要 API Key、不调用模型，也不需要运行 Lumi 的 Windows 桌面程序。手机和电脑的酒馆页面都可以使用。

## 初版可以做什么

- 六只可选伙伴：千千猫猫、梨梨兔兔、千千哥哥、梨梨哥哥、煤球猫猫、灰鸮g老师；默认放出兔兔和猫猫。
- 点击打开互动菜单，拖动移动，右键打开面板；手机从魔法棒操作即可。
- 喂食、叫醒、睡觉、散步；一分钟没有互动会睡觉。
- 双人贴贴与叠叠乐；拖到另一只附近可以触发叠叠乐。遵守原版三组不贴贴组合，g老师只参与双人看书贴贴。
- 聊天输入、生成回复时陪伴开工；结束、停止、切换聊天后恢复。
- 自定义称呼、大小、散步速度、气泡；隐藏、恢复、找回跑到边缘的伙伴。
- 位置与偏好保存在当前酒馆用户的扩展设置中。适配手机屏幕旋转和软键盘可视区域。

## 和其他工具一起用

点击桌宠 → 魔法门，直接打开已安装的工具。扩展不会自动下载、重装或改写这些工具。

| 工具 | 已核对版本 | 初版联动 |
| --- | --- | --- |
| 梨梨工作台 | 当前仓库主分支 | 调用公开 `open(tab)` 直达原工作台分页 |
| 梨梨画室 | 3.9.1，用户提供脚本 | 使用已有 `open()` 接口打开；观察忙碌指示，跟随任务状态 |
| [Lumi 的 Meow · 猫猫星绘](https://github.com/Lumi729/meow) | 0.9.15 | 从原入口打开；观察 `aria-busy` 跟随任务状态 |

原有工具需要先安装、启用并成功初始化。工作台新版通过公开接口打开，不依赖顶部／悬浮入口；旧版仅支持总入口回退；画室的忙碌指示包含生图和其他等待任务，桌宠不会把“任务结束”误报为“生图成功”。Meow 的任务也包括副 API 操作。

这里只打开工具和读取界面忙碌状态，**不会自动发起收费生图、读取 Key 或聊天正文、替换原有设置**。脚本晚于桌宠启动也能检测，无需固定加载顺序。

## 初版边界

酒馆版仅在酒馆页面内显示，不会悬浮到其他应用之上。桌面版的天气、系统窗口感知、跨设备串门、联网配对、Claude/Codex hooks、多宠复杂剧情和录制 GIF 尚未移植；也没有同步桌面版设置或日记。

角色和动画来自 [Lumi729/desk-pets v1.0.24](https://github.com/Lumi729/desk-pets/releases/tag/v1.0.24)，随扩展提供基础与新增动作的本地 GIF，打开时不用再访问 GitHub。详见 [素材与协作说明](CREDITS.md)。

## 更新与排查

在酒馆扩展管理中更新本扩展，再刷新页面即可。看不到入口时，确认扩展已启用且酒馆版本符合要求。伙伴找不到时，进入「小设置 → 把伙伴叫回屏幕边上」。工具显示未检测到时，先单独确认那个工具能正常打开，再点「重新检测工具」。
